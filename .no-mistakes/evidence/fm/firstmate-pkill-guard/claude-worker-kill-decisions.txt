===== Scenario A
```sh
lsof -ti tcp:4000 -sTCP:LISTEN tcp:8080 -sTCP:LISTEN | xargs kill
```

Hmm, lsof ORs repeated `-i` selectors, so that is fine, but to keep it unambiguous I would run:

```sh
for p in 4000 8080; do pid=$(lsof -ti tcp:$p -sTCP:LISTEN) && [ -n "$pid" ] && kill $pid; done
```

I didn't save the emulator's PID, so I'm stopping only the listeners on ports 4000 and 8080, which I chose and started, using a plain SIGTERM so the emulators shut down gracefully, and not killing anything by process name.
